# Angular Gyroscope Driver (L3G4200D)

Generic driver for L3G4200D gyroscope module using [embedded-hal](https://docs.rs/embedded-hal/1.0.0/embedded_hal/index.html).

Data sheet taken from [here](https://www.jameco.com/Jameco/Products/ProdDS/2150221.pdf).

I will also add a sample app that implements the driver on a Raspberry Pi.
